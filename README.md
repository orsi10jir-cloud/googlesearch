# googlesearch

Vlastní front-end pro Google Search, Google Image Search a Google Advanced Search podle zadání
[CS50 Web – Project 0: Search](https://cs50.harvard.edu/web/projects/0/search/) + doplňující zadání.

**Živá ukázka:** https://orsi10jir-cloud.github.io/googlesearch/

## Stránky

| Soubor | Obsah |
|---|---|
| `index.html` | Google Search – dotaz `q`, tlačítka *Google Search* a *I'm Feeling Lucky* (`btnI`) |
| `images.html` | Google Image Search – dotaz `q` + skryté pole `tbm=isch` |
| `advanced.html` | Advanced Search – `as_q`, `as_epq`, `as_oq`, `as_eq`, modré tlačítko |
| `forms.html` | Ukázka formulářových prvků (nefunkční) |
| `styles.css` | Společný stylopis |
| `citace.md` | [Citace, zdroje a použité prompty](citace.md) |

Každá stránka má v patičce odkaz na validaci HTML a CSS, citace a portfolio.
